# 🛒 Vanilla JavaScript & Fetch API - Shopping Cart Application

Bu proje; **Fetch API**, **Async/Await** ve **mockAPI** servisleri kullanılarak geliştirilmiş, dinamik veri çekme ve sepet yönetimi süreçlerini içeren modern bir web uygulamasıdır.

## 🚀 Öne Çıkan Özellikler

- **Asenkron Veri Çekme:** `mockAPI` üzerinden ürün verilerinin `Fetch API` ve `Async/Await` yapısıyla dinamik yüklenmesi.
- **Dinamik Sepet Yönetimi:** Sepete ürün ekleme, miktar arttırma/azaltma ve ürün silme işlemleri.
- **Anlık Fiyat Hesaplama:** Sepetteki ürünlerin fiyatı ve genel toplam tutarının anlık güncellenmesi.
- **Responsive Tasarım:** Mobil, tablet ve masaüstü cihazlara tam uyumlu arayüz.

## 🛠️ Kullanılan Teknolojiler

- **HTML5 & CSS3** (Flexbox & Grid)
- **Vanilla JavaScript** (ES6+, Fetch API, Async/Await, DOM Manipülasyonu)
- **mockAPI** (RESTful API)
